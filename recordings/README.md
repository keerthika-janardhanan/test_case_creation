This folder contains recorded sessions created by the recorder.

- Each subfolder is a session (e.g., 20250101_120000 or custom name).
- Artifacts include:
  - metadata.json: actions and pageContextEvents
  - dom/: P-###.html (page events), A-###.html (actions)
  - screenshots/: P-###.png (page events), A-###.png (actions)
  - network.har and trace.zip when enabled
